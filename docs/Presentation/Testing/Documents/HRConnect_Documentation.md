# HRConnect (Foundation)

Employee & Leave Management System

## Purpose
Build a full Employee & Leave Management System with frontend, backend, APIs, DB, authentication, and testing.

## Roles
- Employee: Apply and view leave
- Admin: Manage employees and approve leave

## Features
- Register / Login
- Employee CRUD
- Leave Request & Approval

## Tech Stack
Frontend: React / Angular
Backend: ASP.NET Core
DB: SQL Server

## APIs
POST /api/auth/register
POST /api/auth/login
POST /api/leaves
GET /api/leaves/mine

## Testing
- Unit Testing
- API Testing
- UI Automation

## Notes
- Follow SOLID principles
- Use layered architecture
